# Technova-Sales-Report-
## 📊 Project Overview

This project presents an interactive Sales Analysis Dashboard developed using Microsoft Power BI. The dashboard provides insights into sales performance, revenue, profit, products, and regional trends.

## 🎯 Objectives

- Analyse overall sales performance
- Track key sales KPIs
- Identify top-performing products
- Analyse regional sales trends
- Understand profit and revenue performance
- Support data-driven business decisions

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Analysis
- Data Visualization

## 📈 Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Average Sales
- Profit Margin

## 📊 Dashboard Features

- Interactive KPI Cards
- Sales Performance Analysis
- Product-wise Sales Analysis
- Regional Sales Analysis
- Profit Analysis
- Interactive Filters and Slicers

## 📂 Project Files

- Technova.pbix – Power BI Dashboard
- Technova.xlsx.xlsx – Sales Dataset
- Technova_Company_Sales_Analysis... – Project Documentation
- Screenshot...png – Dashboard Screenshot
